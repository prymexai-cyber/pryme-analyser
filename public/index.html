        Welcome to Pryme Quant 👋

        1. Pick your account. Demo to practise, Real to track your broker trades. Set the balance with Edit balance.
        2. Add a free AI key. ⚙️ → Add key (Groq or Gemini are free). Without a key Pryme still gives setups from its own engine.
        3. Choose a market & symbol, then tap Analyse with AI. You get 3–4 setups with Entry, SL and TP, graded A+ to C.
        4. Take a trade. "Take on Demo" or "Took on Real". Pryme watches the live price — TP1, TP2 and SL close automatically and the next setup appears.

        Signed in? Everything is saved to your Google account automatically — look for Saved at the top.

        Google login is not switched on yet

        Google login and cloud save need a free Firebase project. Do this once (about 10 minutes):

        1. Create a projectconsole.firebase.google.com → Add project.
        2. Turn on Google sign-inBuild → Authentication → Get started → Google → Enable → Save.
        3. Allow this websiteAuthentication → Settings → Authorized domains → Add
        4. Create the databaseBuild → Firestore Database → Create → Production mode → asia-south1. Then Rules → paste firestore.rules from the project → Publish.
        5. Copy the web configProject settings ⚙️ → Your apps → Web (</>) → Register → copy apiKey, authDomain, projectId, appId.
        6. Add them on RenderRender → your service → Environment → add FIREBASE_API_KEY, FIREBASE_AUTH_DOMAIN, FIREBASE_PROJECT_ID, FIREBASE_APP_ID → Save. After the redeploy, reload this page.
