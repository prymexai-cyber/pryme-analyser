Put the TradingView Advanced Charts library files here.

After TradingView approves you (https://www.tradingview.com/advanced-charts/ -> "Get the library"),
you get access to the private GitHub repo  tradingview/charting_library.
Download it and copy the CONTENTS of its "charting_library" folder into this folder, so that this file exists:

  public/charting_library/charting_library.standalone.js

Then commit + push. Pryme detects it automatically and draws your Demo/Real positions on the TradingView chart.
Keep your GitHub repo PRIVATE (the TradingView licence does not allow publishing the library publicly).
